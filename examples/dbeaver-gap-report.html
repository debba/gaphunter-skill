01

Executive Summary

No team collaboration

The #1 cited gap across all sources. Connections, queries, and notebooks are local-only with no sync or sharing mechanism.

NoSQL locked behind paywall

MongoDB, Redis, and Cassandra require DBeaver PRO. Tabularis can offer them free via its open plugin architecture.

No app-level security

"Anyone with my device can see all my connections." No PIN, no session lock, no authentication layer.

No live SQL linting

Semantic validation only runs at execution time — unknown tables and columns produce cryptic error messages only after running the query.

ER diagrams not exportable

DBeaver cannot export schema diagrams as SVG, PNG, or UML. Tabularis has the SchemaDiagramPage but lacks export too.

Tabularis already has AI

Text-to-SQL, query explanation, and MCP agent integration are already implemented — a clear differentiator vs DBeaver Community.

Negative Review Analysis

Missing Functionality 5 findings
No team collaboration or shared workspaces High G2 Capterra TrustRadius

Connections, saved queries, and notebooks are strictly local. No sync, no shared query library, no role-based access. Teams work around this by duplicating config files manually.

"Lacks support or weak implementation for team-based workflows." — Capterra reviewer, 2025
NoSQL databases require paid PRO license High G2 Capterra

MongoDB, Redis, Cassandra, and other NoSQL engines are gated behind the enterprise license. The community edition only supports SQL databases via JDBC.

"Requires PRO version for NoSQL database connectivity." — Capterra reviewer, 2024
No app-level authentication or session lock High Capterra

The application has no login screen, PIN, or biometric lock. Any person with physical or remote access to the machine can view all database connections, credentials, and queries.

"The fact that it didn't really have a login system, basically anyone who has my device is able to check my codes etc." — Joel K., Capterra (April 2026)
No active query monitor or kill mechanism Medium Spotsaas Reddit

There is no Activity Center showing running queries across connections. Users cannot cancel a long-running query from the UI — they must open a terminal and use pg_cancel_backend / KILL manually.

"An activity center where you can see threads would be nice." — Spotsaas reviewer, 2025
No live SQL semantic validation Medium G2 GitHub

Syntax highlighting exists, but there is no real-time check against the actual schema. Unknown table names or columns are only detected at execution time, often with cryptic driver-level error messages.

"SQL error messages are somewhat cryptic which makes debugging cumbersome." — Capterra reviewer, 2023
Export & Interoperability Gaps 2 findings
Schema/ER diagrams cannot be exported Medium Capterra G2

The built-in ER diagram viewer is useful but locked inside the app. No export to SVG, PNG, PDF, or UML formats — making it useless for documentation, architecture reviews, or third-party design tools.

"Cannot export Entity Relationship Diagrams as UML files for use with other tools." — Capterra reviewer, 2024
Export/import workflow is confusing and limited Low Capterra

Data export and import UX is complex and poorly documented. Multiple steps and cryptic options make it error-prone for non-expert users.

"Export import could be made easier." — Capterra reviewer, 2024
UX & Workflow Friction 3 findings
No auto-refresh of database structure High G2 Capterra

After creating a table, running a migration, or altering schema externally, DBeaver requires a manual tree refresh or full restart to reflect changes. Critical friction in CI/CD-adjacent workflows.

"An area that can be improved is the auto reload of databases once a new DB is created on any environment." — Capterra reviewer, 2024
Query history not persistent across sessions High GitHub Reddit

History is lost between sessions or across different editor windows. No full-text search in history. This is a feature request open since 2018 (GitHub Issue #4303) with no resolution.

"Automatically save recent executed SQL, keep it after closing DBeaver and allow user to consult this list." — cesarmansur, GitHub Issue #4303 (2018, still open)
Cluttered UI overwhelms new users Medium G2 Capterra Beekeeper

DBeaver exposes all features at once with a Java IDE paradigm. The comparison most cited: "it's Eclipse, not VSCode." Navigation is dense and the learning curve is steep for occasional users.

"Sometimes the UI can feel a bit too cluttered and new users might be a bit overwhelmed." — Capterra reviewer, 2025
